# 30 · 路线图

## 当前状态（v1.0 · 2026-10-22）

- ✅ Web / PWA 跑通：瀑布流、双维筛选、详情拆解、收藏、搜索、离线
- ✅ 内容数据层与代码分离，带 schema + 校验脚本
- ✅ 多端目录预留（android / ios）
- ⏳ 内容量：9 套搭配（**当前最大短板**）

## M2 · 内容填充（最重要，先做这个）

目标：30 套以上，覆盖 7 风格 × 5 场景不留空档。

- [ ] 补齐每个风格至少 4 套（当前商务 2、极简 2，其余各 1）
- [ ] 补齐场景：聚会（party）目前是空的
- [ ] 每套配齐 4–6 个单品，`note` 写清版型/材质要点，不写空话
- [ ] 图片统一 720px 宽、画幅在 0.6–0.75 之间错开
- [ ] `editorials.json` 增加到 6–8 张（配色、面料、尺码、保养等）

> 填充方式：图片放进 `content/images/looks/`，复制模板写进 `content/looks.json`，跑 `node scripts/check-content.mjs`。

## M3 · 体验打磨

- [ ] 无限滚动 / 分页（内容 > 40 套时再考虑）
- [ ] 详情页左右滑动切换上一套 / 下一套
- [ ] 收藏分组（「通勤」「想试」自定义分组）
- [ ] 搜索历史与热门标签
- [ ] 骨架屏（首屏比现在更稳）
- [ ] 深色模式

## M4 · 账号与同步（需要云服务）

- [ ] 手机号 / 邮箱登录
- [ ] 收藏云端同步 + 多端一致
- [ ] 离线优先：本地写入、联网后合并
- [ ] 替换 `storage` 对象即可，UI 不动

## M5 · Android 上架

- [ ] PWA 审核（manifest、图标、HTTPS、离线可用）
- [ ] TWA 打包（Bubblewrap / PWABuilder），生成 AAB
- [ ] 应用签名、Google Play 素材（截图、描述、隐私政策）
- [ ] 国内分发备选：自有渠道包 / 应用宝

## M6 · iOS

- [ ] WKWebView 壳 + 原生启动图
- [ ] App Store 素材与隐私清单
- [ ] 若上架受阻，先以 PWA「添加到主屏幕」交付

## 明确的非目标

- 电商导购 / 返利链接
- 用户投稿与社区互动
- 潮流资讯与发售日历

## 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 图片版权 | 无法商用 | 正式版替换为自有拍摄或已授权素材 |
| 内容量不足导致留存低 | 高 | M2 优先，先把库做厚 |
| AI 生成图质感不统一 | 中 | 统一 prompt 与后期（同一背景、同一光比） |
| 纯本机收藏换设备即丢失 | 中 | M4 上账号同步 |
