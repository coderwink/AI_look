# 00 · 产品概览

## 一句话

给「不知道怎么穿」的男生一个可以照着抄的穿搭库 —— 看图、看单品、看配色，收藏起来下次照着穿。

## 解决什么问题

市面上的穿搭内容都在社交平台里，刷完就散：图片好看但不知道买了什么、什么牌子、什么版型。
这个 App 把「一套 look」拆成可执行的信息：**图 → 单品清单（含版型要点）→ 配色 → 一条提醒**。

## 目标用户

- 20–35 岁男性，愿意花心思但不想研究时尚理论
- 场景驱动：明天要面试 / 第一次约会 / 出差三天带什么
- 需要一个「样板库」，而不是潮流资讯

## 核心体验（当前已实现）

1. **瀑布流浏览**：双列错落，像刷小红书一样快速扫搭配
2. **风格 / 场景双维筛选**：日系、街头、商务、极简、机能、复古、半正式 × 日常、通勤、约会、出行、聚会
3. **详情拆解**：大图 + 搭配思路 + 单品清单 + 配色色卡 + 编辑提醒 + 相关推荐
4. **收藏**：一键存起来，「我的」页统计
5. **搜索**：按风格、单品、颜色、场景关键词
6. **PWA**：添加到安卓桌面，全屏、可离线

## 设计原则

| 原则 | 具体做法 |
|---|---|
| **图优先** | 界面黑白灰，不抢图片；卡片只有图 + 标题 + 作者行 |
| **信息可执行** | 每个单品都带版型/选购要点，不写「好看」「高级」这类空话 |
| **一屏一案** | 详情页读完就能去下单，不需要再跳转 |
| **内容与代码分离** | 全部内容在 `content/*.json`，改内容不碰代码 |
| **不做社交** | 没有评论、点赞数、关注。收藏是私人行为，不做比较 |

## 不做什么（当前阶段）

- 不做电商闭环（不接购买链接、不做比价）
- 不做用户投稿 / 社区
- 不做 AI 穿搭推荐（先把内容库做厚）
- 不做复杂账号体系（收藏存本机即可）

## 成功的样子

内容库 100+ 套搭配，覆盖 7 种风格 × 5 种场景，用户能在 30 秒内找到「明天穿什么」，并收藏 5 套以上。
